# ObsidianQ GitHub Pages Template

This folder contains a publish-ready static page for showcasing ObsidianQ.

## Files

- `index.html` - project landing page content
- `styles.css` - page styling
- `assets/` - screenshots/video placeholders

## Add Your Media

Place media files in `docs/site/assets` using these names (or update `index.html`):

- `screenshot-file-tab.png`
- `screenshot-secure-contacts.png`
- `screenshot-vault.png`
- `video-poster.png`
- `demo.mp4`

## Publish on GitHub Pages

1. Push this repository to GitHub.
2. In GitHub repo settings, open **Pages**.
3. Set source to your default branch.
4. Set folder to `/docs` (or `/docs/site` if your repo/page settings support that path directly).
5. If using `/docs`, either:
   - move `index.html` and `styles.css` up to `/docs`, or
   - keep this structure and point Pages to `/docs/site`.

## Optional

- Add a `CNAME` file if you use a custom domain.
- Add Open Graph images/meta tags for better link previews.
