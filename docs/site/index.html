ObsidianQ

Secure File Encryption for the Modern Era

ObsidianQ is a local-first encryption toolkit that combines password workflows, Secure Contacts key exchange, and encrypted vault operations in one practical desktop application.

View on GitHub Download Latest Release

What It Solves

ObsidianQ helps you protect files and text without relying on external cloud key services. It supports both simple password encryption and trusted key-based exchange for teams.

Local-First by Design

  • Encryption and decryption run on your machine
  • Private keys remain under your control
  • Public identities are exchanged directly between users

Security Architecture

  • Post-Quantum Key Exchange: ML-KEM-768 (Kyber)
  • Authenticated Encryption: XChaCha20-Poly1305
  • Password Hardening: Argon2id
  • Hashing & Fingerprints: BLAKE3
  • Chunked Engine: integrity-oriented large-file processing

ObsidianQ is designed for practical security and transparent workflows. Security claims should always be validated against current release notes and code.

Performance Snapshot

  • Typical encryption on modern hardware: approximately 1.2-1.4 GB/s
  • Decryption performance varies by storage, workflow, and mount mode
  • Real-world throughput depends on hardware, file size, and I/O profile

Quick Start

  1. Set up your identity in Secure Contacts.
  2. Add trusted contacts or use password-based protection.
  3. Encrypt files, protect text, inspect packages, or work in a secure vault.

Best Practices

  • Verify fingerprints before trusting a contact
  • Back up private keys securely
  • Use strong passwords in password mode
  • Store recovery material safely
  • Keep ObsidianQ updated
