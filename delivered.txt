  Critical design note

  ml-kem 0.3.x is still a pre-release (Feb 2026) and its dependency chain (sha3 0.11-rc) has a compile error. Used
  pqcrypto-kyber 0.8 instead — same algorithm (FIPS 203 / ML-KEM-768), stable, compiles clean.

  Extension points (marked in code)

  - engine.rs — swap full-RAM read for streaming per-chunk I/O
  - engine.rs — add seek_decrypt() for random-access partial decryption
  - crypto/aead.rs — add new SuiteId variants without touching the engine
  - crypto/kdf.rs Argon2Params — tune memory/time cost
  - format.rs — version field allows future format evolution
