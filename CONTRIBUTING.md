# Contributing to ObsidianQ

Contributions are welcome and appreciated.

Before submitting large changes, please consider opening a GitHub
issue to discuss the proposal.

## Areas of Interest

Helpful contributions may include:

• security reviews
• cryptographic design feedback
• bug fixes
• performance improvements
• documentation improvements
• usability improvements

## Code Style

Please follow the existing style and keep changes focused.

## Security Changes

If your contribution affects cryptographic logic or key handling,
please describe the design clearly in the pull request so it can
be reviewed properly.

## Responsible Disclosure

If you discover a security vulnerability, please follow the
process described in SECURITY.md rather than opening a public issue.
